# سوبر ماركت الجمال — مشروع أندرويد (Capacitor)

هذا مشروع أندرويد جاهز (بُني بواسطة Capacitor) يحتوي نفس نظام الإدارة والمحاسبة،
ومتصل بنفس قاعدة بيانات Supabase التي يستخدمها تطبيق سطح المكتب — أي أن أي
عملية تسويها على الموبايل (بيع، إضافة منتج...) بتظهر مباشرة عالابتوب، والعكس
صحيح، لأنهم يشتركون بنفس الحساب السحابي بالضبط (نفس السيرفر، نفس البيانات).

## ⚠️ ليش ما بنيت لك ملف APK جاهز مباشرة؟

بيئة العمل اللي أشتغل فيها ما عندها وصول لخوادم أدوات بناء أندرويد الرسمية
(Google Maven وGradle الرسمي) بسبب قيود شبكة الإنترنت المفروضة عليها تحديداً
— جربت فعلياً وطلعت رسالة رفض (403) من هالخوادم. هاي مو مشكلة بالمشروع نفسه،
المشروع جاهز 100% ويبني عادي على أي جهاز عادي عنده Android Studio.

## طريقة الحصول على ملف APK (خطوة واحدة تقريباً)

1. نزّل ونصّب **Android Studio** (مجاني): https://developer.android.com/studio
2. افتح Android Studio > Open > اختر مجلد `android` الموجود جوا هذا المشروع.
3. اصبر لين يخلص التزامن التلقائي لأول مرة (بيحمّل هو نفسه كل الأدوات اللي يحتاجها
   من الإنترنت، هذا طبيعي ومرة وحدة بس).
4. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
5. الملف الناتج بيطلع بمسار: `android/app/build/outputs/apk/debug/app-debug.apk`
6. انقل هذا الملف لموبايلك (عبر كيبل، بلوتوث، جوجل درايف...) وثبّته
   (لازم تفعّل "تثبيت من مصادر غير معروفة" بإعدادات الأندرويد أول مرة).

## بديل أسرع بدون Android Studio إطلاقاً (يشتغل الآن فوراً)

بما إن التطبيق أصلاً صفحة ويب واحدة متصلة بنفس قاعدة البيانات، تقدر تستخدمه
على موبايلك مباشرة بدون أي APK:

1. انقل ملف `www/index.html` (الموجود جوا هذا المشروع) لموبايلك (واتساب لنفسك،
   جوجل درايف، إيميل...).
2. افتحه من متصفح **Chrome** على الموبايل.
3. من قائمة الثلاث نقاط بكروم: **"إضافة إلى الشاشة الرئيسية" / Add to Home screen**.
4. رح تصير عندك أيقونة على شاشة موبايلك تفتح النظام بواجهة كاملة الشاشة
   بدون شريط متصفح — نفس شكل تطبيق حقيقي، ونفس الحساب ونفس البيانات
   المتزامنة مع الابتوب فوراً (لأنه نفس Supabase بالضبط).

هذا الخيار عملياً بيعطيك نفس تجربة الـ APK تقريباً، وجاهز الآن بدون انتظار
تنصيب أي برنامج.

## ملاحظة مهمة
عدّل `capacitor.config.ts` إذا حبيت تغيّر اسم التطبيق أو الـ App ID لاحقاً،
وأعد تشغيل `npx cap sync android` بعدها (يحتاج Node.js مثبت على جهازك).
